# Enneagram Test

Aplikasi tes Enneagram ringan berbasis HTML, CSS, dan JavaScript vanilla.

## Fitur

- 45 pertanyaan skala 1 sampai 5
- Skor untuk 9 tipe Enneagram
- Hasil tipe utama, kemungkinan wing, dan chart skor
- Responsive untuk desktop dan mobile
- Tidak membutuhkan dependency

## Menjalankan lokal

Buka `index.html` langsung di browser.

Atau jalankan server kecil dengan Node:

```powershell
node server.js
```

Lalu buka `http://localhost:5173`.
